Windows 前端项目部署工具（EXE 版 v1.1.1）
========================================

双击“前端项目部署工具.exe”打开图形界面。

项目部署：
1. 点击“管理项目”配置项目名称和目标目录。
2. 选择主程序或语言包，选择或拖入 ZIP。
3. 核对目录后点击“开始部署”。
4. 工具完整替换旧目录；失败时自动恢复旧目录。

Nginx 管理：
1. 选择 nginx.exe 与 nginx.conf。
2. 可以编辑和格式化 nginx.conf。
3. 保存前自动执行 nginx -t；失败时不覆盖原文件。
4. 支持 UTF-8、GBK、GB18030、UTF-16 和手动按编码重载。
5. 支持启用、停用和平滑重载 Nginx。

请不要把工具放进任何项目的部署目录中。
历史备份不会自动删除，请定期清理。
